# 久留米文化街ガイド ── 福岡県三大歓楽街、昭和が残る夜の街

**メタディスクリプション(案)**: 久留米市日吉町・通町に広がる「文化街」を自社データで解説。福岡県三大歓楽街の一つとされる歴史的背景と、深夜営業が集まる飲食店の実態を紹介する久留米文化街ガイド。

---

## 文化街とは

文化街は久留米市日吉町を中心とするエリアで、久留米市随一の歓楽街とされる。博多・中洲(福岡市)、堺町(北九州市)と並んで**福岡県三大歓楽街**の一つに数えられ、名前の由来は戦後に日吉町に建てられた映画館「文化会堂」にある。昭和30〜40年代に最盛期を迎えたという([Wikipedia「文化街」](https://ja.wikipedia.org/wiki/%E6%96%87%E5%8C%96%E8%A1%97))。

西鉄久留米駅から文化街までの距離は、出典によって「徒歩13分」「徒歩15分前後」といった幅がある([note「久留米・文化街をひとりでぶらり。」](https://note.com/regal_acacia3736/n/n941aa2a03c12))。当サイトに掲載している個別店舗の徒歩データでも、10分程度から20分程度まで幅があり、店によってばらつきが大きい。この「駅から10分以上」という距離感が、一番街・二番街とは違う客層・時間帯を持つ街になっている一因と考えられる。

## データで見る文化街:接待業態が全体の多くを占める街

当サイトの集計では、文化街エリアの掲載店舗数は151店(2026年8月22日時点)で、当サイト全体(285店)の半数以上を占める。ただしその内訳を見ると、次のように大きく偏っている。

| 業態区分 | 店舗数 |
|---|---|
| バー | 11店 |
| 居酒屋 | 21店 |
| コンカフェ | 3店 |
| シーシャ | 2店 |
| **一般的な飲食店 計** | **37店** |
| スナック・キャバクラ・クラブ・ラウンジ・ガールズバー(接待を伴う業態) | 114店 |
| **合計** | **151店** |

一番街・二番街・駅周辺の3エリアでは、接待を伴う業態の掲載はごく一部かゼロだった。文化街だけが、スナック・キャバクラなどの接待業態が店舗数の大半を占めており、これが「福岡県三大歓楽街」と呼ばれる歴史的背景と重なっている。

これらの接待業態は2026年7月30日に社長判断で公開されたばかりで、営業時間・料金などの情報が未確認の店も多い。本ガイドでは、こうした業態が数多く集まっているという事実の紹介にとどめ、個別の店名は挙げない。詳しい情報を探す場合は、福岡県料飲業生活衛生組合連合会が公開している久留米文化街社交組合の組合員一覧なども参考になる([福岡県料飲業生活衛生組合連合会「久留米文化街社交組合(筑後ブロック)組合員一覧」](https://f-ryoin.jp/union/kurume-bunkagai))。

## 文化街=焼き鳥の街でもある

久留米市は市内に約180軒の焼き鳥店があり、人口1万人あたり7.46軒という数字で「焼き鳥店の人口比日本一」と紹介されている([久留米公式観光サイト「Welcome to KURUME」](https://welcome-kurume.com/enjoys/gourmet/foods_03.html)、[久留米ファン](https://kurumefan.com/kurumeyakitorifesta2025))。この焼き鳥文化の一角を、文化街に掲載されている焼き鳥店も担っている。

## まとめ

- 文化街は西鉄久留米駅から徒歩13〜15分程度、久留米市随一の歓楽街で、福岡県三大歓楽街の一つとされる。
- 当サイトの掲載151店のうち、バー・居酒屋・コンカフェ・シーシャといった一般的な飲食店は37店。残る114店はスナック・キャバクラなど接待を伴う業態で、この比率の高さが「歓楽街」らしさを裏付けている。
- 一般的な飲食店の中には、翌3〜6時まで営業する店が複数あり、4エリアの中で最も深夜営業が集中している。
- 焼き鳥店も多く、久留米市が「焼き鳥店人口比日本一」とされる文化の一角を担っている。
